## Course Outcome
What you will be able to do by the end of this course.

1. Ability to create prototypes which are suitable with elements from current project, and technically feasible to turn into real implementation
2. Ability to create real products with around 3 iterations for each feature, not just a personal project used locally
3. Ability to learn when the need arises, acknowledge the existence of tools to serve future needs

## Learning Principles
1. It's totally ok to be wrong, that's just the nature of learning - Prediction Error
2. Store knowledge in an external Personal Knowledge Management tool: Obsidian, Excalidraw
3. Intentionally make it answer slowly and concisely
4. Before going high, you have to dive low first, especially when the ground is not solid
5. Always read and understand the implementation plan/solution: either come up with a different implementation plan, or summarize them into an easy-to-review one

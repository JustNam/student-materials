## What is VS Code?

VS Code is the code editor you'll use to write, read, and navigate your project's code alongside Claude Code.

## Required Setup

- **Prettier**: install the Prettier extension, set it as your default formatter, and enable format-on-save.
- **Claude Code**: install the Claude Code extension.
- **Theme**: set to `Light (Visual Studio)` → `Visual Studio Light`.

## Basic Operations

- `Cmd/Ctrl + Shift + F` - search across the whole project.
- Hold `Cmd/Ctrl` and hover over a variable or function - peek its original implementation.
- Click a variable - see all its occurrences highlighted on the scrollbar.
- `Cmd/Ctrl + P` - quick file open by name.

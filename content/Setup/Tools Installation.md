Most of tools required in this course could be installed directly from Terminal (their instruction are written in `red`). First, have a quick read of this doc:

[[What is Terminal?]]

Then, you could install these tools. If you have trouble installing tools via Terminal, you could install Claude Code first and then ask it to install them for you:

## Lesson 1

- Claude Code: `curl -fsSL https://claude.ai/install.sh | bash`
- VScode: https://code.visualstudio.com/download
- NPM: `npm install -g npm`
- Chrome: https://www.google.com/chrome/

## Lesson 2

- Supabase CLI: `brew install supabase/tap/supabase`
- Docker desktop: https://www.docker.com/products/docker-desktop/
- Deno: `curl -fsSL https://deno.land/install.sh | sh`

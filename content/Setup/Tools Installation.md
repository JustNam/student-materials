Most of tools required in this course could be installed directly from Terminal (their instruction are written in `red`). First, have a quick read of this doc:

[[What is Terminal?]]

Then, you could install these tools. If you have trouble installing tools via Terminal, you could install Claude Code first and then ask it to install them for you.

- Claude Code:
    - macOS/Linux: `curl -fsSL https://claude.ai/install.sh | bash`
    - Windows (PowerShell): `irm https://claude.ai/install.ps1 | iex`
- VScode: https://code.visualstudio.com/download - see [[VS Code]] for required setup and basics
- NPM: `npm install -g npm`
- Chrome: https://www.google.com/chrome/
- Supabase CLI:
    - macOS/Linux: `brew install supabase/tap/supabase`
    - Windows (PowerShell): `scoop bucket add supabase https://github.com/supabase/scoop-bucket.git` then `scoop install supabase`
- Docker desktop: https://www.docker.com/products/docker-desktop/
- Deno:
    - macOS/Linux: `curl -fsSL https://deno.land/install.sh | sh`
    - Windows (PowerShell): `irm https://deno.land/install.ps1 | iex`

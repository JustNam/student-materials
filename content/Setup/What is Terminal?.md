## What is the Terminal?

The Terminal (also called Command Line or Shell) is a text-based interface for talking to your computer. Instead of clicking buttons, you type commands and the computer responds with text — less pretty than the graphical interface, but far more powerful and precise.

## Why It Matters (Especially for AI-Assisted Building)

For PMs building with AI, the Terminal is non-negotiable:

- **It's where AI coding tools live.** Claude Code, package installers (npm, pip), and git all run in the Terminal. Real products get built here, not in a GUI.
- **It's the universal language of developers.** Every tutorial and AI instruction assumes you can open a Terminal and paste a command.

## How to Open the Terminal

### On macOS 🍏

1. Press `Cmd + Space` to open Spotlight Search
2. Type `Terminal`
3. Press `Enter`

Alternative: Open Finder → Applications → Utilities → Terminal.

### On Windows 🪟

Windows has several options — use **Windows Terminal** (modern, recommended):

1. Press the `Windows` key
2. Type `Terminal` (or `PowerShell` on older systems)
3. Press `Enter`

Alternative: Right-click the Start button → select "Terminal" or "Windows PowerShell".

## Your First Check

Once open, type this and press Enter:

```
echo "Hello from the terminal"
```

If you see the message echoed back, you're in. That's all it takes to start — every command you'll learn builds on this same simple loop: type, press Enter, read the response.
